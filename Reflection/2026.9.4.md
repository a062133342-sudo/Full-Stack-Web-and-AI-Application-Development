### Four working areas in Git
- working directory
- staging area
- local repository
- remote repository
### Reason of having a staging area
The staging area gives users a choice to pick which files to save.
### Difference between git add, git commit, and git push
- git add: puts file into the staging area
- git commit: saves the files onto the computer
- git push: uploads files from local repository to remote repository
### What is markdown, and why is it useful when working on GitHub?
Markdown is a language to format text with symbols to simplifies the text.
