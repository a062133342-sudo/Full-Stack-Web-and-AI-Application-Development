# learning-a-difficult-concept

### Concept
- pull request

### Part 1: analogy
- A pull request is like a parter to check group work before sharing.
- This analogy helps explain the concept by using example that students may encounter in school.
- "Parter check" is the PR process, and "sharing" is to merge.

### Part 2: Focused and diffuse mode
- Focused mode: I can practice the process of PR through some tesks.
- Diffuse mode: I can take a walk or nap to get idea about PR.
- It is important to use both two methods for understanding.

### Part 3: Learn it over time
1. practice PR once
2. take a break
3. return later to explain PR process

### Reflection
1. What was difficult at first?
- At first, it is difficult to remember users can not push code directly to main branch.
2. What became clearer after you came back to it?
- Having PR process can keeps the main work/branch safe.
3. What do you still need to practice?
- I still need to practice how to fix merging conflicts.
