### What is Github:
a platform for developers to share ideas, and work together on code projects.
### Key vocabulary/workflow of Github:
- issue: problem
- branch: an independent workspace that allows users to develop features, fix bugs, or experiment with code without affecting the main project
- commit: save during the process of doing project
- pull request: a process to review and discuss before merging code
- merge: combine two branches
