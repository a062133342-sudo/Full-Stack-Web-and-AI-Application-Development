### What is Git? 
a version control system that tracks file changes over time
### Why use version control? 
keeps a full history of edits in one place instead of using duplicating files
### Main Git concepts:
Version control is used to track changes
### Git workflow:
working directory to staging area to commit history
### Important terms:
- repository
- staging area
- commit
- branch
### Git commands:
- git status
- git add
- git commit -m"initial commit"
- touch new_file.js
- git init
- git config --global
