### git-rebuild-workflow
1. clone: copy the repository to my local computer
2. create branch: creat a feature branch to add changes with affecting the main branch
3. create index.js: add a JavaScript file
4. add: put changes to the stagging area
5. commit: save the changes
6. push: upload the changes to remote repository

### two rules to remember when making changes to our current files
- run "git add" before "git commit"
- use "git status" to check where you are

### two common mistakes to avoid
- remember to add a space and a period for the "git add ." comand
- run "git switch" before add things in new file
