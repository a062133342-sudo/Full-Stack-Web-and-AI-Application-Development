### Relationship
First, users create files in the working directory, then run git add to move changes in staging area. 
Next, users commit the changes in local repository, finally, type git push to upload the files into the remote repository.

### Markdown syntax
- heading: # for the biggest title, and ###### for the smallest title
- bold and italic text: * makes the words italic, ** makes the words bold, and ***  makes the words both italic and bold
- lists: - at the start of a line makes a bullet point, and numbers make a items in order
- images: ! drops a picture into picture
